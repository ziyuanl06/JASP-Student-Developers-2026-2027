# 🎓 JASP Student Developers Group 2026–27

A student-run, voluntary group at the University of Amsterdam where we learn to develop [JASP](https://jasp-stats.org) together. No grades, no tests, and no coding experience required.

**👉 Course website: https://ziyuanl06.github.io/jasp-student-developers/**

## This year's mission

We're building a **data wrangling module** for JASP, so researchers can get their raw data ready for analysis without leaving JASP.

| Phase | When | What we build |
|---|---|---|
| 🔎 Diagnose | Before Christmas | Tools that *look at* data: missing values, distributions, outliers |
| 🛠️ Fix | After Christmas | Tools that *change* data and export a clean dataset |
